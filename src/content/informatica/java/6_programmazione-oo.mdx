## 1. Introduzione

La **programmazione orientata agli oggetti** (*Object-Oriented Programming*, OOP) è un paradigma che organizza il software attorno a **oggetti**.

Un programma non viene più visto come una sequenza di istruzioni, ma come un insieme di **entità che collaborano tra loro**.

Un oggetto può rappresentare:

- oggetti reali → automobile, studente, telefono;
- concetti astratti → conto bancario, esame, prenotazione.

---

### Classe e Oggetto

- **Classe** → è una sorta di template (modello o progetto) che serve per creare oggetti.
- **Oggetto** → è una specifica istanza concreta della classe.

<Aside variant="info">
Quindi, in altri termini, un oggetto è un'istanza concreta di una classe.
*La classe è come un modello o progetto da cui vengono creati gli oggetti.*
</Aside>

Analogia:

| Concetto | Esempio |
|---|---|
| Classe | Progetto di una casa |
| Oggetto | Casa costruita |

Dallo stesso progetto si possono costruire tante case: avranno tutte la stessa struttura (stanze, porte, finestre), ma ognuna avrà i propri valori (colore delle pareti, indirizzo, proprietario). Allo stesso modo, da una sola classe si possono creare tanti oggetti, ognuno con i propri dati.

![instanza-oggetto](https://media.geeksforgeeks.org/wp-content/uploads/20250906151500826906/420046617.webp)

---

Un oggetto possiede:

- **Stato** → attributi (dati)
- **Comportamento** → metodi (azioni)

---

## 2. Perché usare l'OOP?

L'OOP permette di:

- organizzare programmi complessi;
- riutilizzare codice;
- rendere il software più manutenibile;
- modellare il mondo reale.

Rispetto alla programmazione procedurale:

### Procedurale

- il focus è sulle **funzioni**
- i dati sono separati dal comportamento

### Object-Oriented

- il focus è sugli **oggetti**
- dati e comportamenti sono uniti

## 3. Creazione di una Classe

In Java una classe si definisce con la keyword `class`.

```java
class Persona {
}
```

Questa classe è vuota ma può già creare oggetti.

## 4. Creare un Oggetto (Istanza)

```java
Persona p1 = new Persona();
```

`new` crea un oggetto in memoria.

## 5. Attributi (Stato)

Gli attributi rappresentano le informazioni dell'oggetto.

```java
class Persona {
    String nome;
    int eta;
}
```

Uso:

```java
Persona p = new Persona();

p.nome = "Anna";
p.eta = 25;
```

## 6. Metodi (Comportamento)

I metodi descrivono cosa può fare un oggetto.

```java
class Persona {

    String nome;
    int eta;

    void saluta(){
        System.out.println("Ciao, sono " + nome);
    }
}
```

Uso:

```java
Persona p = new Persona();
p.nome = "Marco";

p.saluta();
```

## 7. Il Costruttore

Il costruttore inizializza l'oggetto quando viene creato: viene eseguito automaticamente ogni volta che si usa `new`, e serve per dare un valore iniziale agli **attributi di istanza**, cioè i dati che appartengono a ciascun oggetto.

![classi e oggetti](https://miro.medium.com/1*SqHq5pwi3OqjjUOLkX1HJA.png)

Ha:

- stesso nome della classe
- nessun tipo di ritorno

```java
class Persona {

    String nome;
    int eta;

    Persona(String nome, int eta){
        this.nome = nome;
        this.eta = eta;
    }
}
```

Creazione:

```java
Persona p = new Persona("Anna", 25);
```

<Aside variant="info">
`this` rappresenta l'istanza corrente, cioè l'oggetto su cui si sta lavorando. Serve per distinguere gli attributi (`this.nome`) dai parametri con lo stesso nome (`nome`). È l'equivalente di `self` in Python, ma in Java non va scritto tra i parametri dei metodi.
</Aside>

## 8. Incapsulamento

L'incapsulamento protegge i dati interni dell'oggetto.

Gli attributi dovrebbero essere privati.

```java
class ContoBancario {

    private String titolare;
    private double saldo;   // attributo privato

    ContoBancario(String titolare, double saldo){
        this.titolare = titolare;
        this.saldo = saldo;
    }

    void deposita(double importo){
        saldo += importo;
    }

    void preleva(double importo){
        if (importo <= saldo) {
            saldo -= importo;
        } else {
            System.out.println("Saldo insufficiente.");
        }
    }

    void mostraSaldo(){
        System.out.println("Saldo attuale: " + saldo + " €");
    }
}
```

Accesso controllato tramite metodi:

```java
ContoBancario conto = new ContoBancario("Luca", 1000);
conto.deposita(200);
conto.preleva(5000);   // Saldo insufficiente.
conto.mostraSaldo();   // Saldo attuale: 1200.0 €

conto.saldo = 0;       // ERRORE di compilazione: saldo ha accesso private
```

<Aside variant="info">
**Analogia del bancomat**: non puoi aprire la cassaforte della banca e prendere i soldi a mano (accesso diretto all'attributo), ma puoi chiedere al bancomat di depositare o prelevare (metodi pubblici). Il bancomat controlla che l'operazione sia valida, ad esempio che il saldo sia sufficiente.
</Aside>

<Aside variant="warning">
A differenza di Python, dove gli attributi "privati" (`__saldo`) sono solo resi meno accessibili e ci si basa sulla fiducia del programmatore, in Java `private` è una regola **controllata dal compilatore**: dall'esterno della classe l'attributo non è proprio accessibile.
</Aside>

```java
        this.nome = nome;

```

### 8.2 Il metodo toString()

Ogni classe Java può ridefinire il metodo `toString()` per avere una **rappresentazione testuale leggibile** dell'oggetto (è l'equivalente di `__str__` in Python). Viene usato automaticamente quando si stampa l'oggetto o lo si concatena a una stringa.

```java
class Punto {

    private int x;
    private int y;

    Punto(int x, int y){
        this.x = x;
        this.y = y;
    }

    @Override
    public String toString(){
        return "Punto(" + x + ", " + y + ")";
    }
}

Punto p = new Punto(2, 5);
System.out.println(p);   // usa automaticamente toString() -> Punto(2, 5)
```

<Aside variant="tip">
Senza `toString()` la stampa mostrerebbe qualcosa come `Punto@1b6d3586` (nome della classe + un codice interno). Vedremo meglio `@Override` nella lezione sull'[ereditarietà](/informatica/java/7_ereditarieta).
</Aside>

## 9. Attributi di Istanza e Statici

### 9.1 Attributi di istanza

Appartengono a una singola istanza (oggetto): ogni oggetto ha il proprio valore.

### 9.2 Attributi statici

Appartengono alla classe e sono condivisi da tutte le istanze.

```java
class Studente {

    String nome;                         // attributo di istanza
    int voto;                            // attributo di istanza
    static String scuola = "ITI Fermi";  // attributo statico (di classe)

    Studente(String nome, int voto){
        this.nome = nome;
        this.voto = voto;
    }
}
```

Uso:

```java
Studente s1 = new Studente("Luca", 8);
Studente s2 = new Studente("Giulia", 9);

System.out.println(Studente.scuola); // accesso all'attributo statico
System.out.println(s2.voto);         // accesso all'attributo di istanza
```

<Aside variant="tip">
Pensa a una classe scolastica: ogni studente ha il **proprio** nome e il **proprio** voto (attributi di istanza), ma la **scuola** è la stessa per tutti (attributo statico).
Se si cambia `Studente.scuola = "Liceo Galilei";`, la modifica è visibile da **tutti** gli oggetti, perché esiste una sola copia dell'attributo.
</Aside>

## 10. Comunicazione tra Oggetti

Gli oggetti collaborano invocando metodi.

```java
Studente s = new Studente();
Registro r = new Registro();

r.aggiungiStudente(s);
```

Gli oggetti si scambiano messaggi (chiamate di metodo).

## 11. Relazioni tra Classi

### 11.1 Associazione

Un oggetto usa un altro oggetto.

### 11.2 Aggregazione / Composizione

Un oggetto contiene altri oggetti.

Esempio:

```java
class Auto {

}
```

## 12. Esempio Completo

```java
class Rettangolo {

    private int base;
    private int altezza;

    Rettangolo(int base, int altezza){
        this.base = base;
        this.altezza = altezza;
    }

    int area(){
        return base * altezza;
    }

    int perimetro(){
        return 2*base + 2*altezza;
    }
}

public class Main {

    public static void main(String[] args){

        Rettangolo r = new Rettangolo(5,7);

        System.out.println(r.area());
        System.out.println(r.perimetro());
    }
}
```
